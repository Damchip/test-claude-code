Dans cPanel O2switch → Comptes de messagerie, crée une boîte (ex. fileservice@ton-domaine.fr) puis « Connecter les appareils » pour lire le serveur SMTP. Port 465 (SSL). Sans réglage, les e-mails sont écrits dans data/mails_non_envoyes.log.

Inspecte un fichier ECU : plateforme et identifiants détectés, et la liste des chaînes ASCII avec leur position. Utile pour affiner la détection — le bouton « Copier le rapport » te permet de le partager.

Un dossier = un original. Original = fichier marqué ORI (ou .ori) · une fiche par type de prestation (Stage 1, FAP off, E85…) ; si plusieurs fichiers du même type, la révision SAV la plus élevée gagne. Aucun fichier n'est déplacé ni modifié.

Pour chaque fichier trouvé dans le dossier (et ses sous-dossiers) : recherche de la meilleure solution connue, puis même analyse que l'onglet Auto-patch. Seuls les fichiers au verdict propre sont patchés automatiquement ; les autres sont signalés pour une vérification manuelle — rien n'est jamais patché à l'aveugle. Les fichiers sources ne sont jamais modifiés ; les fichiers patchés sont écrits dans un sous-dossier _traite.

Applique automatiquement les modifications d'une ou plusieurs solutions (Stage 1 + FAP + E85…) au même fichier client. Les deltas se superposent ; un octet en conflit n'est pas écrit. Calcul 100 % serveur : headers programmeur (KESS, Autotuner…) retirés puis recollés, checksums Bosch additifs ou CRC-16 corrigés si le schéma est clair. Une signature RSA/CSA détectée (PKCS#1) n'est jamais patchée et le fichier n'est jamais dit « prêt à flasher ». Les zones sont nommées (FAP, EGR, SCR, DTC, Stage, E85) d'après la forme et le type de la fiche — sans Damos. Le fichier source n'est jamais modifié.

Portail client

Personnalise la page vue par tes clients (data/portal_config.json). Les changements s'appliquent immédiatement, sans redémarrer le portail.

⚠ Un mot de passe ici bloque aussi tes vrais clients : ils ne pourront plus déposer leur fichier sans le connaître. À n'utiliser que pour un accès restreint (tests, lien privé partagé à des clients choisis). Pour un portail public normal, laisse ce champ vide.
